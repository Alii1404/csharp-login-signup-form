# C# WinForms Login & Signup Application

## 🇦🇿 Haqqında (About in Azerbaijani)

Bu layihə C# Windows Forms istifadə edilərək hazırlanmış dinamik Giriş (Sign In) və Qeydiyyat (Sign Up) interfeysidir. İstifadəçi qeydiyyatı, şifrənin gizlədilib-göstərilməsi və əsas form doğrulama (validation) funksionallıqlarını əhatə edir.

### Özəlliklər
* **Dinamik İdarəetmə:** Bütün form elementləri (Button, TextBox, GroupBox) kod tərəfindən dinamik şəkildə yaradılmışdır.
* **Qeydiyyat Sistemi:** Yeni istifadəçi adı və şifrə ilə sistemə qeydiyyatdan keçmək imkanı.
* **Şifrə Göstər/Gizlə:** Checkbox vasitəsilə şifrənin görünürlüyünü anında dəyişmə.
* **Giriş Yoxlaması:** Boş buraxılmış sahələri təsdiqləyən və istifadəçiyə xəbərdarlıq edən idarəetmə mexanizmi.

### İstifadə Olunan Texnologiyalar
* **Dil:** C#
* **Çərçivə (Framework):** .NET Framework / Windows Forms (WinForms)


## 🇬🇧 About (English)

This project is a dynamic Sign In and Sign Up user interface built using C# Windows Forms. It includes user registration, password visibility toggling, and basic form validation mechanisms.

### Features
* **Dynamic UI Generation:** All form controls (Button, TextBox, GroupBox) are created dynamically via code.
* **User Registration:** Functionality to register with a new username and password.
* **Show/Hide Password:** Instant password visibility toggle using a checkbox.
* **Input Validation:** Validation mechanism to check empty fields and display warning messages.

### Built With
* **Language:** C#
* **Framework:** .NET Framework / Windows Forms (WinForms)
